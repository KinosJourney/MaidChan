# Maid-chan 桌宠 · 使用说明

> 这是一个陪在你桌面上的小女仆「Maid」，来自《樱花庄的宠物女孩》。
> 本文件可以随时手动修改，改完在程序里点「帮助 / 说明 → 重新加载」即可看到最新内容，**无需改代码、无需重启**。

---

## 一、第一次使用（超简单三步）

### 第 1 步：安装 Python
- 打开 https://www.python.org/downloads/ 下载并安装 Python 3。
- Windows 安装时**一定要勾选** `Add Python to PATH`。

### 第 2 步：设置 API Key

- 用文本编辑器打开项目目录中的 `.env` 文件。
- 把新生成的 DeepSeek API Key 填在等号右侧并保存：

```text
DEEPSEEK_API_KEY=你的真实key
```

- **不要把 Key 写进 `oc.py`，也不要分享或提交 `.env` 文件。**

> 若 Key 曾提交、分享或发布，请先到 DeepSeek 控制台撤销旧 Key，再创建新 Key。

### 第 3 步：安装并启动
- **macOS**：双击 `install.command` 安装 → 再双击 `run.command` 启动。
- **Windows**：双击 `install.bat` 安装 → 再双击 `run.bat` 启动。

> 首次双击 `.command` 若提示"无法打开"，请在文件上点右键 → 打开 → 打开。

## 二、怎么和她聊天

- 角色下方有一个输入框，打字后按**回车**或点「发送」。
- 她会用**打字机动画**一句一句地说话。
- **点一下对话气泡**：立刻显示完整的当前这句。
- 显示完后**等 0.5 秒**才能再点，防止手滑点太快。
- 每句说完停留 2 秒自动下一句；最后一句停留 3 秒后淡出消失。

## 三、右键菜单功能

在角色身上点**右键**，可以看到：

| 菜单项 | 作用 |
| --- | --- |
| 历史记录… | 查看全部对话（带时间），可**单条删除**，删了她就真的忘了 |
| 设置 · 人设… | 直接修改她的性格 / 称呼 / 说话风格，保存即生效 |
| 御主档案… | 填你的昵称、生日、关系等，她永远记得你是谁 |
| 帮助 / 说明… | 打开本说明（就是这个文件） |
| 和我打个招呼 | 让她根据时间跟你问好 |
| 设置 · 人设 → 主动陪聊 | 开启后，空闲（未用番茄钟）时她会主动聊新闻 / 八卦 / 哲学 / 稀奇知识 |
| 番茄钟… | 独立番茄钟窗口：实时倒计时、可选 15/25/45/60 分钟或自定义时长、当日完成计数 |
| 待办事项… | 需要提醒的事项清单：可新增 / 编辑 / 完成 / 删除，到点前 2 分钟和到点各提醒一次 |
| 随机播放合集 | 从 B 站合集里随机抽一条，用浏览器打开 |
| 窗口置顶 / 取消置顶 | 是否让她一直显示在最前面 |
| 显示 / 隐藏输入框 | 只想看着她时可以把输入框藏起来 |
| 关闭 / 开启嘴巴动画 | 觉得动画太闹可以关掉 |
| 清空聊天记忆 | 一键让她忘掉所有对话 |
| 退出 | 关闭桌宠 |

## 四、常用操作

- **移动位置**：用鼠标左键按住角色拖动即可，位置会自动记住。
- **换人设**：右键 → 设置 · 人设，改完点「保存并生效」，会自动重置对话上下文。
- **让她记住你**：右键 → 御主档案，填好保存。这些信息每次聊天都会发给她。
- **按住说话**：在任意应用中按住 **Control+Shift+空格** 开始录音，松开后自动识别并发送（Mac 上是 Control 键，不是 Command）。
- **随机播放合集**：右键「随机播放合集」，或按 **Control+Shift+P**（Mac 上是 Control 键，不是 Command）。她会从合集里随机抽一条视频并用浏览器打开。默认合集是 [4小时星露谷大合集](https://space.bilibili.com/599873511/lists/4747084?type=season)，可在「设置 · 人设」里改成别的 B 站合集链接。

## 四点五、语音待办提醒

想让 Maid 帮你记事并到点提醒？有两种方式：

- **语音创建**：点麦克风按钮说一句带时间的话，例如「提醒我下午三点开会」「明天早上八点半吃药」。
  她会识别其中的事情和时间，**自动加入待办清单**，并用气泡告诉你「已加入待办：… 我会在 … 提醒你」；
  想改时间或删除，右键 →「待办事项…」即可。如果这句话只是闲聊（没有明确时间），则不会创建。
- **手动创建**：右键 →「待办事项…」→「新增待办」，填写内容和提醒时间即可。

提醒规则：

- 每条待办会在**到点前 2 分钟**提醒一次，**到点**再提醒一次；两次都用醒目的高优先级气泡并伴随提示音。
- 如果创建时距离截止已不足 2 分钟，会自动跳过提前提醒，只保留到点提醒。
- 待办数据保存在系统用户目录（见下文「我的数据存在哪」），重启不会丢，也不会重复提醒同一条。
- 在「待办事项…」窗口里可以随时**编辑时间、标记完成 / 恢复、删除**。

> 提醒依赖程序保持运行。如果提醒时间到时 Maid 没有开着（关闭 / 休眠期间错过），
> 下次启动或唤醒后她会补发一次「错过提醒」，但不会重复轰炸。

## 四点六、主动陪聊（新闻 / 八卦 / 哲学 / 稀奇知识）

不用番茄钟、又有一阵子没和她说话时，Maid 会**主动**找你聊点有意思的：一条新闻、一段趣闻八卦、一个哲学思考，或一条稀奇冷知识。

**默认是关闭的**，需要在右键 →「设置 · 人设…」最下方的「主动陪聊」区域勾选开启，并可以调整：

- **聊些什么**：新闻 / 趣闻八卦 / 哲学 / 稀奇知识，任意勾选。
- **最短间隔**：两次主动聊天之间至少隔多久（默认 45 分钟）。
- **空闲至少**：距上次互动至少空闲多久才开口（默认 10 分钟）。
- **每日上限**：一天最多主动聊几次（默认 8 次）。
- **免打扰**：设定一个不打扰的时段（默认 23 点到次日 8 点），可跨午夜。

内容来源与注意事项：

- **新闻 / 八卦**来自公开 RSS 源（如 BBC 中文、少数派、36氪、知乎、V2EX 等），是**近期真实内容**，每条都会附带来源（气泡里显示 `via 来源名`，历史记录里保存来源链接，方便追溯）。**需要联网**。
- **哲学 / 稀奇知识**来自本地精选话题池，离线也能聊，且事实确切、不会乱编。
- 只有在**没有使用番茄钟**（专注 / 休息都算在用）且你**处于空闲**时才会触发；你正在打字、录音或她正在说话时都会自动跳过，不会打扰。
- 全部 RSS 源都拉取失败时，会自动回退到本地哲学 / 冷知识话题，不会报错。
- 想让她安静，随时在设置里取消勾选即可，改完立即生效，无需重启。

## 五、打包成独立应用（可选）

不想每次都开终端？可以打包：
- **macOS**：双击 `pack.command`，完成后在 `dist/Maid-chan.app`。
- **Windows**：双击 `pack.bat`，完成后在 `dist\Maid-chan\Maid-chan.exe`。

## 六、开机自动启动（macOS）

想让 Maid-chan 每次开机自动出现？

- **开启**：双击 `开启开机启动.command`，下次登录 Mac 时她会自动出现。
- **关闭**：双击 `关闭开机启动.command`，取消自动启动。

> 开机启动使用的是 macOS LaunchAgent，不需要管理员密码。
> 如果项目文件夹移动了位置，需要重新双击 `开启开机启动.command` 更新路径。

## 七、常见问题

**Q：她说"还没有填写真实的 API Key"？**
A：请检查项目目录中的 `.env` 文件是否已按“第 2 步”填写，然后重新启动。

**Q：提示 401 / API Key 无效？**
A：Key 填错了，或复制时多了空格，重新复制粘贴。

**Q：背景不是透明的 / 有白框？**
A：程序会自动去白底。若图片仍有白边，说明该图不是纯白背景，可换一张更干净的图。

**Q：我的数据存在哪？**
A：聊天记录、设置、档案都存在系统用户目录（不在项目里，升级不会丢）：
- macOS：`~/Library/Application Support/MaidChan/`
- Windows：`%APPDATA%\MaidChan\`
